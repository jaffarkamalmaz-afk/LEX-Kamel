LEX — Kamel Al Hajj Ali | 2026
================================

Personalized Arabic-first graduation tribute website for Kamel.

FILES
- index.html: all page content and messages
- style.css: responsive luxury navy-and-gold design
- script.js: reveal-on-scroll and smooth navigation
- kamel-portrait.jpg: optimized copy of the portrait supplied for this project

VIEW
Open index.html in a modern browser. Google Fonts require an internet connection; local layout and content remain available without them.

PERSONALIZATION
- University: University of Aleppo (جامعة حلب).
- The graduation certificate is a commemorative gift, not an official university credential.
- The friendship message is signed by Jaffar.
- The light legal joke is in the "تنويه قانوني" section.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload all four project files to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Share the generated Pages URL with Kamel.
